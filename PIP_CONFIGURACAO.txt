PIP NAO RECONHECIDO NO WINDOWS
================================

Se ao digitar "pip" o Windows retorna "'pip' nao e reconhecido como comando",
use uma das opcoes abaixo.


OPCAO 1 - USAR PYTHON -M PIP (RECOMENDADO)
-------------------------------------------

Em vez de:
  pip install -r requirements.txt

Use:
  python -m pip install -r requirements.txt

Ou execute o arquivo do projeto:
  instalar_dependencias.bat

Isso funciona sempre que o comando "python" e reconhecido (Python no PATH).


OPCAO 2 - ADICIONAR PIP AO PATH
--------------------------------

O pip fica na pasta Scripts da instalacao do Python. Exemplo:
  C:\Users\SEU_USUARIO\AppData\Local\Programs\Python\Python3XX\Scripts
  ou
  C:\Users\SEU_USUARIO\AppData\Local\Python\pythoncore-3.14-64\Scripts

1. Descubra onde o Python esta instalado:
     python -c "import sys; print(sys.executable)"
   A pasta Scripts fica no mesmo diretorio (subpasta Scripts).

2. Adicione essa pasta Scripts ao PATH do sistema:
     Painel de Controle > Sistema > Configuracoes avancadas do sistema
     > Variaveis de ambiente > Variaveis do sistema > Path > Editar > Novo
     Cole o caminho da pasta Scripts (ex.: ...\Python\Python314\Scripts).

3. Feche e reabra o terminal. Teste: pip --version


OPCAO 3 - REINSTALAR O PYTHON COM "ADD TO PATH"
------------------------------------------------

Ao instalar o Python (python.org), marque a opcao:
  "Add python.exe to PATH"

Depois reinstale ou repare a instalacao e marque essa opcao para que
tanto "python" quanto "pip" funcionem no terminal.


RESUMO RAPIDO
-------------

  python -m pip install -r requirements.txt
  python -m pip install pyautogui Pillow

Ou: duplo clique em instalar_dependencias.bat
